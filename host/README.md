# Nocturna Host (portable)

Electron shell that embeds the Fastify server + SPA for LAN parties.

See the root [README.md](../README.md) section **Deploy without Node on player devices** for build commands (`dist:host:linux`, `dist:host:win`, `dist:host:mac`).

Players never install this app — only the table Host does. Everyone else joins with a phone browser.
